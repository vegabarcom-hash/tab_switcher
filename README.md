# Last Tab Switcher - Chrome Extension

Расширение для браузера Chrome/Comet, которое добавляет функцию переключения между двумя последними открытыми вкладками по горячей клавише **Ctrl+Q**.

## Возможности

- ⌨️ **Ctrl+Q** - переключение между двумя последними использованными вкладками
- 🔄 Работает как Alt+Tab для вкладок, переключает между последними двумя активными вкладками
- 📋 История последних использованных вкладок (MRU - Most Recently Used)
- 🗂️ Автоматически отслеживает активацию, создание и закрытие вкладок
- 🖱️ Контекстное меню для тестирования функции
- ✨ Работает во всех окнах браузера

## Установка

### Способ 1: Распакованное расширение (разработка)

1. Откройте браузер Chrome/Comet
2. Перейдите на `chrome://extensions/` (или `comet://extensions/`)
3. Включите **Режим разработчика** (Developer Mode) в правом верхнем углу
4. Нажмите **Загрузить распакованное расширение** (Load unpacked)
5. Выберите папку проекта (`Last_Tab_Switcher_Extension`)
6. Готово! Теперь можно использовать **Ctrl+Q** для переключения между вкладками

### Способ 2: Упакованное расширение (.crx)

1. На странице `chrome://extensions/` в режиме разработчика
2. Нажмите **Упаковать расширение** (Pack extension)
3. Выберите папку проекта
4. Создаст файл `.crx`, который можно распространять

## Как это работает

- **Service Worker** (`background.js`) ведет список MRU (Most Recently Used) вкладок
- Отслеживает события активации вкладок, их создания и закрытия
- При активации вкладки перемещает её в начало списка MRU
- При нажатии **Ctrl+Q** переключает на вторую вкладку из списка MRU
- При закрытии вкладки удаляет её из списка MRU
- Есть контекстное меню "Switch to Last Tab (Test)" для быстрого тестирования

## Файлы проекта
