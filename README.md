# Last Tab Switcher for Comet

Переключает Comet на последнюю активную вкладку сразу по нажатию **Ctrl+Tab**, без меню выбора вкладок.

## Почему нужен помощник

Comet/Chromium резервирует `Ctrl+Tab` для самого браузера, поэтому расширение не может назначить это сочетание через `chrome.commands`. Расширение принимает разрешённую команду `Ctrl+Q`, а локальный помощник `CometTabHotkey.exe` перехватывает `Ctrl+Tab` только при активном `comet.exe` и передаёт расширению `Ctrl+Q`.

В других программах `Ctrl+Tab` не меняется.

## Установка и обновление

1. Откройте `comet://extensions/`.
2. Включите режим разработчика.
3. Если расширение ещё не установлено, нажмите «Загрузить распакованное расширение» и выберите эту папку.
4. Если расширение уже установлено, нажмите кнопку перезагрузки на его карточке.
5. Запустите `install.ps1` один раз. Скрипт собирает помощник встроенным компилятором Windows, запускает его и добавляет ярлык в автозагрузку.

После этого короткое нажатие `Ctrl+Tab` переключает между двумя последними активными вкладками текущего окна Comet.

## Файлы

- `manifest.json` — Manifest V3, команда расширения и разрешения.
- `background.js` — сохраняемая по окнам MRU-история вкладок.
- `comet-hotkey/Program.cs` — перехват `Ctrl+Tab`, ограниченный процессом Comet.
- `install.ps1` — сборка, запуск и добавление помощника в автозагрузку.

## Резервная проверка

Если `Ctrl+Tab` не срабатывает, сначала проверьте `Ctrl+Q`. Если `Ctrl+Q` переключает вкладку, перезапустите `CometTabHotkey.exe` через `install.ps1`. Если не переключает и `Ctrl+Q`, перезагрузите расширение на `comet://extensions/` и проверьте назначение команды на `comet://extensions/shortcuts`.
